# 06 优化与回归

输入：可复现问题、固定基线、原始回答及实际上下文。

输出：候选配置、同题回归结果、保留或回退决定。

## 操作

1. 从问题清单选定一个有证据的问题，写清失败原句、预期、相关来源和受影响环节；证据不足先补采，不盲改配置。
2. 写明本轮唯一改变因素、预期改善和不可退化的关键行为。例如只改 Prompt，不同时改模型与检索权重。
3. 冻结题集和其他配置，保存基线、候选完整快照及差异。需要调整资料时建立新版本，重新核对来源、条件与分段标注。
4. 按[生成评测](05-生成评测.md)创建新运行目录并真实回归；涉及索引或检索时先重复[召回评测](03-向量化与召回评测.md)。
5. 对比同题、同轮次结果，检查目标问题及原本通过的核心行为、拒答和多轮衔接。不能只比较平均分。
6. 按事先定义的门槛决定保留、回退或继续核查。总通过数提高但关键能力退化时，不能仅凭总分接受候选。
7. 将选定配置实际发布或恢复，核对生效配置，运行关键真实用例，关联新消息与实际输入；不能只确认配置文件被改过。
8. 保存失败候选及决定。原问题没有解决就保留待办，不因执行过一次实验改为已修复。

## 变更范围与重测

- 资料或分块变更：重建受影响索引，复核题目来源与分段身份，再测召回和生成。
- Embedding 模型或向量规则变更：重建文档向量与索引，再测完整基线；不要混用不同空间的向量。
- 仅调用路径变化：先核对模型和预处理兼容性，再执行目标环境真实回归；不能直接沿用旧环境成绩。
- 生成模型或 Prompt 变更：重测生成、拒答、条件和多轮，保留未改动题的回归结果。
- 题集或评分规则变更：建立新版本，注明与旧结果是否可比；不能改标准使当前输出“通过”。

## 取舍记录

记录问题 ID、目标、唯一改动、配置版本、运行目录、逐题变化、关键退化、决定和实际生效版本。随机波动、样本不足或上下文缺失时写证据限制，不宣称已证明优化有效。

确定性测试用于验证会话与统计契约，真实模型回归验证回答能力；不能以规则替身或单元测试代替模型输出。

## 完成条件

- 新旧结果可逐题对照，失败和退化都保留。
- 决定有证据，实际生效配置与选定版本一致。
- 关键路径完成真实验证，未解决问题有状态和下一步。

下一步：[发布与恢复](07-发布与恢复.md)。

案例：[Prompt 单项改动、候选拒绝与恢复记录](../records/Prompt单项优化与回归记录.md)。实验回退也可完成处理流程，不代表质量问题解决。

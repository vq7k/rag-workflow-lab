本目录只规定操作和完成条件。历史配置、样本成绩、截图与取舍决定放在 [实验记录](../records/README.md)，不作为其他环境的默认配置。

## 使用边界

- SOP 可用于不同模型服务和部署环境；仓库脚本当前只支持本机服务，不能直接向共享服务器或远程网关发送凭据。
- 示例脚本的资料、题集和校验规则有专门约束；照着运行可复现实验，换语料须同步适配输入与预期。模板不代表脚本已支持通用导入。
- 从包含 `pyproject.toml` 的项目根目录执行命令；先按根目录 [README](../../README.md) 准备 Python 环境。
- API Key 只放本地 `.env` 或环境变量。共享文档、运行产物和截图前检查凭据、个人信息和知识正文范围。
- 调用成功、确定性测试通过、真实模型质量通过分别记录，不能互相替代。没有真实模型调用，不能完成智能能力验收。

## 起步模板

复制 [题集模板](../../templates/test-cases.json)、[标注表模板](../../templates/review.csv) 和 [发布记录模板](../../templates/release-record.md)，填写实际资料、配置和预期，不复用历史成绩。

每次真实运行单独建立目录，保存版本、输入、原始输出与失败；既有目录用于复核，不覆盖。自动语义评判尚未实现，其后续准入条件见[生成评测](05-生成评测.md)。

# 02 预处理、分块与入库

输入：固定原文、来源清单、资料使用边界。

输出：版本化导入稿、分块规则、分段快照与可用索引。

## 操作

1. 保留原文，生成派生导入稿。识别标题、正文、列表、代码、链接与限定条件；删除导航和重复模板内容，记录转换方法与工具版本。
2. 若使用 LLM 辅助整理，保存模型、Prompt 与改动说明；对照原文检查事实、数字、操作顺序和适用范围，不能把模型补写内容当作来源事实。
3. 选择直接创建、知识流水线或外部知识库接入。一次性验证可先直接导入；重复处理需要可复用流程时评估流水线；已有独立检索服务时再评估外部接口及权限契约。
4. 配置分块规则并预览。检查分隔符、长度、重叠、标题继承及代码边界，记录实际值；不要把某次实验长度当作所有资料的默认值。
5. 挑选定义、步骤、条件例外和相邻主题检查分段。检索只拿到单段时，仍应能识别主题、适用范围和关键前提。
6. 发现截断、混入无关内容或条件脱离正文时，修改导入稿或规则，重新预览；保留前后版本及修改原因。
7. 确认后执行入库，等待全部目标分段索引完成。保存知识库、文档、分段身份及正文快照，核查启用状态和失败项。
8. 抽题做实际检索，核查返回段落是否含完整依据；预览合格不能代替召回与生成验证。

## 检查重点

- 原文事实及重要条件未丢失；正文中不存在解析残留或错误字符。
- 标题足以识别主题，代码和操作顺序不因切块发生语义变化。
- 常见结论与其例外能够共同进入检索上下文，或有明确关联方式。
- 文档更新后旧版本如何停用、删除和替换有记录，避免新旧答案同时召回。

真实 IT 资料中的复杂表格、截图识别、操作步骤与系统版本分支需按实际样本单独设计和验收；当前算法语料未验证这些处理能力。未取得代表性样本前只登记覆盖缺口，不预设已经适用的规则。

## 完成条件

- 原文、导入稿和处理规则可关联，原文没有被覆盖。
- 目标分段正文、身份和索引状态可查；失败项没有被默认为完成。
- 预览问题有修订记录；至少完成一次真实检索核查。

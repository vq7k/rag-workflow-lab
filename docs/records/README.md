# 实验记录索引

本目录记录使用中文《Hello 算法》验证本地 RAG 开发闭环的过程。时间线、实例 ID、当时的配置及失败观察保留为证据，不是其他环境必须复制的做法。通用操作入口为 [开发 SOP](../sop/README.md)。

## 本轮范围与结果

六篇候选原文中，仅栈章节 stack-v2 入库，共六段；生成开发集为四道单轮与一组两轮。使用真实 BGE-M3 与本地生成模型，接口成功与人工质量判断分开报告。

| 检查 | 本轮结果 |
|---|---|
| 混合召回 | 三道有答案题 Hit@1、Hit@3、MRR@3 均为 1 |
| v1 生成 | 六轮真实调用成功，人工整体通过 2/6 |
| v2 候选 | 通过 4/6，但核心要点退化，拒绝候选并恢复 v1 |
| 发布与恢复 | DSL 副本真实验证通过；原网页四次核心检查通过，严格质量通过 2/4 |
| 页面证据 | 经人工确认显示正常；最终检查无截图，历史截图另行保留 |

这是小样本开发结果，不是正式 IT 服务台效果准出；条件遗漏、无依据补充、慢请求和展示问题仍保留。

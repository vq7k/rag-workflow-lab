> 在 Python 中，可以使用列表（list）作为栈来实现相关操作。具体方法如下：
>
> - **查看栈顶元素**：使用 `stack[-1]` 访问列表的最后一个元素，即栈顶。
> - **弹出元素**：使用 `stack.pop()` 方法移除并返回栈顶元素。
> - **判断是否为空**：使用 `len(stack) == 0` 判断列表长度是否为 0。
>
> 示例代码如下：

```python
# 初始化栈
stack: list[int] = []

# 元素入栈
stack.append(1)
stack.append(3)
stack.append(2)
stack.append(5)
stack.append(4)

# 访问栈顶元素
peek: int = stack[-1]

# 元素出栈
pop: int = stack.pop()

# 获取栈的长度
size: int = len(stack)

# 判断是否为空
is_empty: bool = len(stack) == 0
```

> 以上操作的时间复杂度均为 $O(1)$。

以下由原回答截图转录，属于网页证据，不是 Provider 原始响应：

> 数组实现的栈在入栈时可能会变慢，是因为当入栈元素超出数组当前容量时，会触发扩容机制。扩容过程需要分配新的、更大的内存空间，并将原有元素复制过去，这导致该次入栈操作的时间复杂度从通常的 O(1) 变为 O(n)。
>
> 链表实现的栈不会遇到同样的问题。链表在扩容时非常灵活，不需要像数组那样预先分配连续内存或进行整体复制，因此不存在因扩容导致单次入栈操作效率显著降低的情况。不过，链表入栈需要初始化节点对象并修改指针，其基础操作效率通常低于数组，但性能表现更加稳定。

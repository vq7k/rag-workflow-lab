# Dify 本地流程操作

1. 打开 http://localhost ，使用原账号。先检查已有模型配置，不覆盖原应用。
2. 确认生成模型与 Embedding 模型分别可真实调用；若需要外部服务，遵守本机代理约束。API Key 仅配置到本地密钥设置，不写入本项目。
3. 创建知识库 `IT-public-sample-v0`，上传 `knowledge/import/` 中 3 个 Markdown 文件。选择真实 Embedding，初次按标题/段落检查切分，等待索引成功。
4. 创建 Chatflow `IT-helpdesk-local-v0`，配置知识检索 → LLM → 回答；开启引用。首版指令：根据资料回答，注明适用系统；资料不足时明确说明；缺少操作系统或错误信息时先追问；公司地址、账号、密码不得编造。
5. 调试逐题输入 `evaluation/cases-v0.jsonl` 的问题，检查检索命中、回答和引用。把模型/配置版本、原始输出、耗时、错误和人工判定记入 `runs/`，保留首次成绩。
6. 开发题完成后另建未用于调参的验收题；冻结配置，运行真实回归。首轮只做人工评分，不引入额外评测平台。
7. 发布到 Dify 自带网页，并从发布页重测有答案、无答案、追问各一题。记录发布时的 DSL（若当前版本支持导出）、模型与知识库配置。

人工转接首期只提供联系服务台的说明；未接通工单系统时，不显示“已转交/已建单”。

完成条件：知识入库、真实检索与模型调用、来源引用、无答案处理、发布页验证均留有记录。目前以上步骤尚未执行。
